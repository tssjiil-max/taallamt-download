# تعلّمت — Clean Core v1

هذا الفرع هو بداية إعادة بناء النظام التعليمي بنواة مستقلة عن التصميم.

## المبادئ
- مصدر بيانات واحد للحقيقة.
- واجهتان فقط: المعلم والطالب/ولي الأمر (نفس صفحة الطالب).
- التصميم طبقة قابلة للاستبدال ولا يغيّر منطق النظام.
- التقويم الشامل هو مركز التشغيل: أكاديمي + سلوكي، ويغذي المتابعة، ملف الإنجاز، النجوم، والخطة العلاجية.
- عدم إدخال تقييم لا يعني عدم إتقان.
- الخطة العلاجية تبدأ آليًا بعد تكرار عدم الإتقان 3 مرات لنفس المهارة.
- سقف التحفيز الشهري 30 نجمة، وشكابومبو واجهة التحفيز.
- الغياب المدرسي خارج النظام؛ السلوك الصفي والتأخر عن الحصة قابلان للتوثيق.
- الخطة الأسبوعية تُجهز من المنهج والتوزيع وجدول الحصص وتظهر للطالب أسبوعيًا.
