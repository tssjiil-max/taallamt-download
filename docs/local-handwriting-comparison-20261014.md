## أدوات الإعادة

`scripts/local-htr-probe.py` و`scripts/local-trocr-probe.py` أدوات بحث منفصلة عن تقييم المنتج. تتطلب بيئة Python محلية وأوزانًا مثبتة وmanifest خاصًا خارج المستودع بالشكل:

```json
{"samples":[{"id":"sample-1","image":"/private/path.jpg","box":[10,20,200,80],"reference":"نص قراءة بشرية"}]}
```

المرجع يستعمل للمقارنة بعد الاستدلال فقط، ولا يمرر إلى النموذج. الناتج الخاص لا ينشر؛ يحتفظ بالنص الخام والمرجع ووقت القراءة، دون درجة أكاديمية. ينبغي مراجعة ترخيص كل نموذج وبياناته قبل استخدامه خارج هذا الاختبار التعليمي.
