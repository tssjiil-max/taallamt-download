# هيكلة تعلّمت المرنة

## المبدأ
لا تُثبّت أسماء المواد أو الطلاب أو المهارات في منطق الواجهة. كل عنصر يرتبط بفصل دراسي ويمكن تفعيله أو أرشفته أو تغييره لاحقًا، مع حفظ التاريخ السابق.

## الواجهات
1. **لوحة المعلم**: الإدارة الأساسية للطلاب والمواد والمهارات والتقييم والمهام والخطط والتقارير وملف الإنجاز.
2. **بوابة ولي الأمر**: متابعة ابنه والتواصل وطباعة الخطة العلاجية، مع جلستين متزامنتين كحد افتراضي (جهازان).
3. **صفحة الطالب**: واجهة مستقلة عن ولي الأمر للمهام والتقدم والتحفيز، ولا تستخدم كواجهة إدارة.

## الكيانات الأساسية
- terms: الفصول الدراسية.
- subjects: المواد لكل فصل.
- students: الطلاب وحالتهم النشطة/المؤرشفة.
- skills: المهارات المرتبطة بالمادة والفصل.
- evaluations: تقييم الطالب (متقن / أتقن البعض / يحتاج تدريب).
- assignments: الواجبات والمهام.
- guardianSessions: جلسات ولي الأمر، بحد افتراضي جهازين لكل طالب.
- specialFollowUps: ملفات المتابعة الخاصة المبنية على ما يذكره ولي الأمر وملاحظة المعلم.
- remedialPlans: الخطط العلاجية.
- messages: التواصل المرتبط بالطالب.
- teacherPortfolio: عناصر ملف إنجاز المعلم.

## المتابعة الخاصة
تقبل حالة صحية مؤثرة، ضعفًا أو صعوبة تعلم، متابعة سلوكية، ظرفًا أسريًا أو حالة أخرى. النظام يقترح تكييفات مدرسية ومتابعة قابلة للقياس فقط؛ لا يقدم تشخيصًا أو علاجًا طبيًا. عند عدم التحسن يقترح مراجعة الخطة أو الإحالة للجهة المدرسية/المختص المناسب.

## شكابمبو
شكابمبو شخصية صفية مستقلة. المرحلة الحالية تعمل **بمحادثة ChatGPT Plus فقط**: النظام يختار الطالب والمهمة ويجهز Prompt قابلًا للنسخ ثم يفتح ChatGPT. لا يوجد API ولا إرسال تلقائي لبيانات الطلاب في هذه المرحلة، والاسم الأول فقط هو الوضع الافتراضي. لاحقًا يمكن إضافة تكامل صوتي/ذكاء اصطناعي دون تغيير بقية الهيكلة.

## قواعد مهمة
- الأرشفة هي الافتراضي بدل الحذف النهائي.
- تغيير الفصل أو المادة لا يحذف تاريخ الطالب.
- الطباعة مهيأة لـ A4 وتخفي أزرار التحكم.
- ولي الأمر في الإنتاج لا يرى إلا الطالب المرتبط بجلسة وصوله.
- وضع اختيار الطالب في بوابة ولي الأمر وصفحة الطالب حاليًا هو للمعاينة أثناء البناء فقط.
- التخزين الحالي في localStorage نموذج أولي للتجربة؛ الاستخدام الحقيقي يحتاج Backend وقواعد صلاحيات وجلسات آمنة.

## مراحل التنفيذ
1. الهيكلة والواجهات الأساسية — تم.
2. إدارة الطلاب والفصول والمواد محليًا — بدأت وتعمل كنموذج أولي.
3. استيراد التوزيع والمهارات من الملفات المعتمدة.
4. نقل التخزين إلى Backend آمن وربط جلسات ولي الأمر.
5. التقييم التفصيلي والخطة العلاجية والتواصل والملفات.
6. الطباعة وملف الإنجاز وPWA ثم اختبار الإنتاج.
