# هيكلة تعلّمت المرنة

## المبدأ
لا تُثبّت أسماء المواد أو الطلاب أو المهارات داخل الواجهة. كل عنصر يرتبط بفصل دراسي ويمكن تفعيله أو أرشفته أو تغييره لاحقًا.

## الواجهات
1. **لوحة المعلم**: الإدارة الأساسية للطلاب والمواد والمهارات والتقييم والمهام والخطط والتقارير وملف الإنجاز.
2. **بوابة ولي الأمر**: متابعة الطالب والتواصل والطباعة، بدون صفحة طالب مستقلة.

## الكيانات الأساسية
- terms: الفصول الدراسية.
- subjects: المواد لكل فصل.
- students: الطلاب وحالتهم النشطة/المؤرشفة.
- skills: المهارات المرتبطة بالمادة والفصل.
- evaluations: تقييم الطالب (متقن / أتقن البعض / يحتاج تدريب).
- assignments: الواجبات والمهام.
- guardianSessions: جلسات ولي الأمر، بحد افتراضي جهازين لكل طالب.
- specialFollowUps: ملفات المتابعة الخاصة.
- remedialPlans: الخطط العلاجية.
- teacherPortfolio: عناصر ملف إنجاز المعلم.

## قواعد مهمة
- الأرشفة هي الافتراضي بدل الحذف النهائي.
- تغيير الفصل أو المادة لا يحذف تاريخ الطالب.
- الطباعة مهيأة لـ A4 وتخفي أزرار التحكم.
- ملف المتابعة الخاصة لا يقدم تشخيصًا أو علاجًا طبيًا؛ يركز على التكييف والمتابعة المدرسية والإحالة عند الحاجة.
- ولي الأمر لا يرى إلا الطالب المرتبط بجلسة وصوله.

## مراحل التنفيذ
1. الهيكلة والواجهات الأساسية.
2. ربط التخزين وقواعد الصلاحيات.
3. استيراد الطلاب والتوزيع والمهارات من الملفات المعتمدة.
4. التقييم والخطة العلاجية والتواصل.
5. الطباعة وملف الإنجاز وPWA.
