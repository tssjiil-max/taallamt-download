# تسليم تجربة التصحيح البصري — 14 أكتوبر 2026

الحالة: تنفيذ جزئي قابل للمراجعة، وليس محرك تصحيح مستقل مثبت الدقة. الفرع preview/shakabumbo-pilot-20261013 فقط. لا دمج ولا تعديل درجات رسمية ولا خدمات مدفوعة أو إرسال صور أطفال لخدمة خارجية.

## المنفذ
محاولة OCR عربية محلية حقيقية Tesseract.js 7 مع نموذج محفوظ ببصمته وترخيصه. توجيه EXIF، نسخة محسنة محافظة، قناع أحمر لنسخة القراءة، الأصل الملون محفوظ، قصاصات حسب مناطق يحددها المعلم، نص خام ومؤشر محرك غير معاير وأسباب إخفاق. واجهة المعلم تعرض القصاصات والقراءة والمفتاح وتسمح بتحرير التفريغ. التقييم الخادمي بعد تحقق المعلم يدعم وزن السؤال والمعيار الجزئي وnull لغير المقروء، مع نطاق للدرجة بدل درجة كلية وهمية. لا نجمة لنتيجة غير مكتملة. منع تكرار التقييم، تحقق مصدر السؤال والصورة وربط المهمة داخل المعاملات. المهلة 20 ثانية للمحاولة و8 ثوانٍ لتهيئة المحرك، وحفظ الصورة مع سبب الإخفاق بدل انتظار غير محدود.

## التحقق البرمجي والمراجعة
npm test: 65 اختبار Vitest و30 اختبار Node في التشغيل المحلي النهائي؛ البناء الكامل ناجح، والاختبارات المستهدفة ستسجل مع رقم التعديل. مراجعة مستقلة كشفت سباق ربط المصدر، وقفل الإجابة غير المقروءة، ومهلة OCR؛ عولجت مع اختبارات. حُسن محاكي Firestore ليثبت بيانات snapshot بدل قراءة متغيرة، وصحح معرف جلسة في اختبار قديم لم يكن يطابق مسار الخادم. اختبارات البيانات الاصطناعية المنطقية ليست دليل قراءة بصري. اختبار بوابة HTTP الفعلية كشف غياب توجيه learning_activity_photo، وكشف استبعاد صور النشاط الاصطناعي من ملف الجلسة؛ أصلح الاثنان، واختبر رفع JPEG مع محرك OCR الحقيقي وظهور الشاهد وعزل الجلسات وتجاهل درجة جهاز الطالب. اختبرت تهيئة المحرك وقراءة صورة بعد تحويله محليًا إلى CommonJS، مطابقًا لصيغة بناء Vercel.

## القيود المتبقية
- كشف حدود الورقة وتصحيح المنظور والميل الهندسي غير منفذين؛ المنفذ توجيه EXIF فقط.
- فصل المطبوع واليدوي يعتمد على تحديد المعلم، وتداخل الأحمر مع نقاط أو تشكيل الطالب يحتاج مراجعة الأصل.
- لا اختبار مرخص لخطوط أطفال متعددة ولا مرجع بشري للصورة المطلوبة، فلا نسبة دقة HTR.
- لا نموذج مستقل موثوق للتنوين، لا منح درجة أو نجمة من OCR وحده.
- لا نسخ موثقة كاملة من لغتي ودليله/الإسلامية/أنا أقرأ أو بنك مفاتيح مصادق عليه؛ تقرير الفحص يوضح مصدر كتاب الإملاء السابق.
- أنواع التوصيل والاختيار والترتيب لا تملك كشفًا بصريًا متخصصًا بعد.
- لا إثبات على هاتف Android أو قياس أمان قاعدة البيانات والنشر الحي حتى إجراء الرحلة التجريبية.
