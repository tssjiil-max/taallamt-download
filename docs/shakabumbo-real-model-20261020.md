# شكابمبو — نموذج المنهج الحقيقي

Preview فقط. Cloudflare Workers AI: `@cf/qwen/qwen3-30b-a3b-fp8` مع `/no_think` لتجنب استهلاك المخرجات في التفكير دون إجابة.

- يستخرج الخادم الدرس والسؤال من الكتالوج الفعلي بعد التحقق من وصول الطالب؛ لا يعتمد نص درس يرسله المتصفح ولا يرسل مفاتيح الإجابات أو بيانات الطالب للمزوّد.
- يستبعد مادة القرآن وطلبات التلاوة والتجويد قبل الاستدلال. لا تغيير في التلاوة أو التكرار الموجودين.
- سياق آخر أربع رسائل، و180 رمزًا للمخرجات؛ الإجابة قصيرة والفشل صريح دون الرجوع إلى رد ثابت مزيف.
- حد مركزي متسلسل 150 طلبًا يوميًا في Durable Object مستقل؛ الخدمة محمية بسر خادمي مخصص لفرع Preview ولا توجد مفاتيح في المتصفح أو المستودع. لا ترقية لخطة مدفوعة.
- الردود المؤجلة بعد الإغلاق تُهمل، وطلب المتصفح يُلغى؛ يتوقف الاستماع أثناء انتظار النموذج ونطقه.
- الصوت: أولوية لصوت الجهاز العربي بسرعة 0.85؛ الملفات القديمة احتياطية. لم يُفعّل Orpheus لعدم وجود اتصال Groq أو مفتاح مهيأ. لا ادعاء باعتماد جودة صوت جديد.
- الحركة: إزالة تعليق التجوال على hover لتجنب سكون الشخصية بعد لمس الجوال، مع بقاء حدودها داخل الصفحة.

التحقق: 120 اختبار Vitest و30 اختبار محرك التعلم، و35 اختبار API ضمن البناء؛ TypeScript وVite وبوابات الانحدار ناجحة. اختبارات النموذج تشمل حجب القرآن، عدم إرسال الإجابات، رفض غير المخول ونفاد الحصة، وإغلاق المحادثة أثناء طلب مؤجل. اختبار Cloudflare حقيقي بمحتوى اصطناعي أنتج جوابًا عربيًا عن تنوين الكسر. جودة الصوت وميكروفون طفل فعلي يحتاجان اختبار هاتف.
