## التغييرات

- عرض الصورة الأصلية الكاملة فقط، المشتقة من `design/shakabumbo/originals/04-standing-white-hair-star.png`. أُوقفت وضعية الترحيب المولدة؛ الميل والترحيب والمكافأة بتحريك الجسم الكامل، دون تركيب أو قص أو تحريك مفاصل.
- مالك مركزي واحد لجلسات الصوت. بدء جلسة ثانية يوقف الأولى فورًا. القراءة المستقلة والتلاوة توقفان الميكروفون قبل إخراج الصوت. استدعاء اكتمال مكرر لا يفتح مستمعين. تنظيف مكون الجلسة القديمة لا يلغي صوت مالك الجلسة الجديدة.
- منع مسار النطق العام عندما تكون المادة قرآنًا، ومنع المجيب المحلي من إعادة آيات عبر طلب القراءة. مسار التلاوة المعتمدة الموجود مستمر.
- النص التعليمي المعروض/المخزن لم يُعدّل. إعداد النطق منفصل، ويستخدم NFC فقط: قد يعيد ترتيب علامات Unicode المتكافئة، ولا يحذف الحركة أو التنوين أو الشدة.
- الصورة نفسها تفتح وتغلق الجلسة. النص اختيار ثانوي. الحالات: الاستماع، التفكير، الكلام، التوقف، الكتم والخطأ.
- محادثة متتابعة محدودة بدرس الطالب، وليست مساعدًا عامًا أو صوتًا فوريًا مع مقاطعة.
- لا خدمات مدفوعة ولا مفاتيح جديدة. الملفات العربية المسجلة محليًا أولًا، ثم صوت الجهاز للمحتوى الجديد عند توفره.
- أضيف فرع Preview المحدد بالاسم إلى قائمة السماح واختبار رفض الإنتاج والفروع الأخرى؛ لم تتغير بيانات/مخططات/تقييمات/دخول المعلم أو إعدادات الإنتاج.

## الأدلة الآلية

`npm test`: نجح 112 اختبار Vitest في 18 ملفًا، و30 اختبار Node للتعلم.
`npm run build`: نجحت بوابات الانحدار، و34 اختبار API، وTypeScript وبناء Vite.

اختبارات مضافة أو موسعة:
- ثلاث جولات باستخدام محرك الجلسة الحقيقي والمجيب المحلي ومهايئ تشغيل الملفات الحقيقي، مع بدائل لواجهات الميكروفون وAudio فقط.
- لا استماع أثناء الصوت؛ استئناف بعد النهاية فقط؛ إغلاق يجهض الميكروفون ويرفض callbacks المتأخرة.
- منع ملكية جلستين وإلغاء الميكروفون من القراءة المستقلة أو القرآن.
- رفض الإذن، عدم الدعم، محدودية إعادة المحاولة، أخطاء الإخراج.
- حماية القرآن؛ الحفاظ على «كَسْرَتَيْنِ»، الحركات، التنوين، المدود والشدة؛ اختيار صوت ar-SA عند توفره.

فشل اختبار ملكية الجلسات وتكرار callback وحماية القرآن قبل الإصلاح، ثم نجح بعده. تصحيح توقع اختبار ترتيب علامات NFC كان في الاختبار فقط، مع إبقاء النص الأصلي ثابتًا.

## ما لا تثبته الاختبارات الآلية

- جودة النطق ومخارج الحروف تحتاج استماعًا بشريًا، خصوصًا «كَسْرَتَيْنِ». مقارنة النصوص ونجاح تشغيل MP3 ليسا اعتمادًا لغويًا.
- الميكروفون السحابي لا يثبت ثلاثة أسئلة بصوت طفل حقيقي أو اختلافات Safari/Chrome على الجوال. جولات المحرك محاكاة واجهات وليست تعرفًا حيًا.
- لا اعتماد نهائي للشكل والصوت قبل موافقة صاحب المشروع وتجربة هاتف فعلي.
