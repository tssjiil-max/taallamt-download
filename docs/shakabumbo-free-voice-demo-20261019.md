## ما تغير
- صورة الشخصية الأصلية الكاملة، مصغرة إلى WebP بحجم 46KB، دون رأس منفصل أو جسم مرسوم. حركات ميل وقفزة خفيفة للصورة الكاملة؛ ليست مشيًا مفصليًا ولا مزامنة فم.
- مساحة للشخصية داخل تدفق صفحة الطالب، وحوار modal متوافق مع لوحة المفاتيح لا يختبئ خلف شريط التنقل.
- فتح الشخصية يبدأ التعرف العربي مباشرة عند دعم المتصفح والسماح بالميكروفون؛ الرد عبر SpeechSynthesis ثم إعادة الاستماع. الكتابة مخفية كخيار احتياطي.
- إلغاء التعرف قبل الصوت، وإبطال callbacks المتأخرة عند الإغلاق والكتم وتغيير الدرس والقرآن. أخطاء الإذن والشبكة وعدم دعم الصوت ظاهرة. توقف بعد ثلاث دورات صمت.
- سياق الدرس والسؤال فقط؛ حجب الشرح والتلميح أثناء الاختبار. سجل الجلسة في الذاكرة، يحذف عند الإغلاق وتغيير النشاط، ولا يرسل إلى API الموقع.
- الحفاظ على تشكيل النص الصوتي. لا ادعاء بصحة نطق «كَسْرَتَيْنِ» دون استماع بشري؛ لا تسجيلات صوتية معتمدة متوفرة ضمن المشروع.
- /shakabumbo-demo معاينة مستقلة بلا قاعدة بيانات أو درجات، مع محاكاة القرآن واختبار الكلمة ووضع شرح دون ميكروفون موسوم بأنه عرض معد، وإطارات responsive=1 بعروض 360/390/430.

## الخدمات والتكلفة
لا حزم أو اشتراكات أو مفاتيح أو اتصالات AI جديدة. التعرف على الكلام قد يستخدم خدمة مزود المتصفح عبر الإنترنت؛ ليس محركًا محليًا مضمونًا. جودة وتوفر أصوات العربية على جهاز العرض يجب اختبارهما فعليًا. النشر على مشروع Vercel Preview الحالي فقط، دون تغيير Production أو إعداداته.

## التحقق المنجز قبل النشر
- npm test: 88 حالة Vitest و30 حالة Node ناجحة.
- npm run build: جميع بوابات الانحدار الحالية و33 اختبار API ثم TypeScript وVite نجحت.
- 12 اختبارًا جديدًا: منع التقاط الرد، الاستئناف بعد انتهاء الصوت فقط، الإغلاق والكتم، رفض callbacks المتأخرة، رفض الإذن، الصمت المحدود، فشل الصوت، الكتابة بلا ميكروفون، حفظ التشكيل، حجب تلميحات الاختبار، قراءة السؤال الحالي، وأسئلة المتابعة.
- لا يثبت ذلك تشغيل الميكروفون الحقيقي أو سلامة النطق أو اختبار هاتف أندرويد فعلي. تُسجل معاينة المتصفح والنشر في ملحق لاحق دون تحويل الاختبارات الاصطناعية إلى دليل صوتي.
