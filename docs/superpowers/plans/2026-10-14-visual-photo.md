# Visual photo pilot implementation plan

المواصفة الملزمة: أمر المستخدم في هذه الجلسة، وتقرير docs/visual-correction-audit-20261014.md. التنفيذ هنا على الفرع التجريبي؛ لا خدمات صور خارجية ولا اعتماد إنتاج.

- [x] فحص المكونات وإعادة استخدام homeworkEvidence وaccess وSharp وواجهة المعلم.
- [x] حزم نموذج العربية المحلي بترخيصه وبصمته، وتشغيل OCR فعلي لا TextDetector أو إجابة ثابتة.
- [x] فصل نسخة القراءة عن الأصل، قناع أحمر محافظ، مناطق المعلم وقصاصاتها، مؤشر محرك غير معاير بلا درجات آلية.
- [x] ربط صور الأنشطة بسؤالها وإصدار المصدر، منع استبدال الصورة بعد التقييم داخل transaction، إعادة التحقق من المصدر عند حفظ المراجعة.
- [x] حالات المقارنة الخمس وأوزان المعلم، null لغير المقروء بدل الخطأ، نطاق تقدير عند عدم اليقين، لا نجمة عند عدم اليقين.
- [ ] مقارنة بصرية فعلية بعينات اصطناعية مرخصة؛ تقرير نتائج خام دون إخفاء الفشل.
- [ ] اختبارات الصلاحيات والحماية والتنوين والأوزان، البناء الكامل، مراجعة مستقلة للتعديل.
- [ ] دفع تعديل الفرع التجريبي وتحديد نتيجة نشره إن أمكن؛ لا دمج.

قرارات: لم تُستخدم صورة حقيقية سابقة لأن المرفق المرجعي غائب هنا؛ الخط المطبوع الاصطناعي لا يثبت HTR. الكشف الآلي لحدود الورقة وتصحيح المنظور غير منفذين، والمعلم يحدد الإجابات. لا محرك موثوق للتصحيح المستقل ثبتت دقته؛ عدم التقييم أفضل من التخمين. اختبار حماية النشاط القديم كان يحسب hash بفاصل جلسة مختلف عن الخادم؛ صحح الاختبار ليطابق المعرف الحقيقي. لا ادعاء اختبار Android من أدوات Node.
