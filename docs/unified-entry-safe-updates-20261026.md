# تعلّمت: الدخول المشترك وحماية استمرارية الطلاب

## النطاق المعتمد
- المشروع: tssjiil-max/taallamt-download فقط. الأساس: فرع PR #22 عند 42f5a5e.
- رابط دخول مشترك: الطالب يختار اسمه ورمزه الخاص من ستة أرقام؛ المعلم بكلمة السر الحالية، دون بريد إلكتروني.
- استعمال واجهة مشتركة مع بقاء صلاحيات الخادم منفصلة. لا دمج لحسابات المعلم والطالب.
- اعتماد إصلاح PR #21 لاستكمال النسخ الاحتياطي؛ لا إصدار للرموز قبل اكتمال النسخة.
- إبقاء روابط أولياء الأمور القديمة، سجلات النجوم والواجبات، الجلسات والتصميم.

## التنفيذ
1. دمج ملفات إصلاح النسخة الاحتياطية من c0c969f دون دمج الفرع أو تغيير بيانات حية.
2. StudentLogin نموذج مشترك يتبدل داخله نوع المستخدم؛ TeacherApp يستعمله عند غياب جلسة المعلم.
3. نقل رسائل خطأ دخول المعلم إلى النموذج المشترك مع الاحتفاظ بالتمييز بين الرفض، القفل، غياب الإعداد والخادم وانقطاع الشبكة.
4. إضافة اختبار عرض لكل وضع، وتشغيل اختبار استكمال النسخة ضمن البناء.
5. تعطيل نشر Vercel التلقائي لهذا الفرع فقط؛ لا تغيير لخدمة الإنتاج الحالية.

## ما يثبته التحقق المحلي
- عرض اختيار الطالب والرمز ذي الستة أرقام، وعرض كلمة سر المعلم دون طلب بريد.
- اختبار الخادم student-login-regression يثبت في مخزن تجريبي أن تغيير مرجع النشر لا يبطل جلسة الطالب وأن النجوم والواجبات والروابط محفوظة.
- اختبار backup-resume-regression يثبت حفظ موضع النسخة واستكمالها بعد تجاوز الحصة ومنع البدء عند تعذر التخزين.
- فحوص البناء واختبارات الوحدة وفحص هوية Firebase المحلي؛ لا تعني اختبارات على بيانات حقيقية أو موقع منشور.

## بوابة النشر المتبقية
- لم يُثبت معرّف مشروع Firebase. إعداد FIREBASE_PROJECT_ID في Vercel محمي ولم تُرجع الأدوات قيمته؛ لا اختيار بالتخمين.
- لم يُثبت إعداد WIF/IAM أو اكتمال نسخة بيانات الطلاب الحية.
- ما زال نقل API والمهام المجدولة وتوافق ملفات جلسات __session وعزل Staging مطلوبًا وفق PR #22.
- قبل الإنتاج: اختبار متصفح منشور للمعلم والطالب وولي الأمر؛ إبقاء طالب مسجلاً أثناء تحديث تجريبي ثم التحقق من الجلسة والنجوم والواجبات والروابط، ومقارنة البيانات قبل/بعد، وتجربة الرجوع.
- لا تحديثات قسرية أو تغيير تلقائي للرموز أو مفاتيح الجلسات. أي تغيير يخص واجهة المعلم يلزمه اجتياز اختبارات الطالب أيضًا.
- لا ضمان مطلق لغياب الأعطال؛ لا يُقبل الإصدار حتى يجتاز هذه البوابة. الإنتاج وحذف Vercel وتغيير بيانات الطلاب يحتاج موافقة صريحة.
