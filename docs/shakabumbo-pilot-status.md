# شكابمبو — حالة التجربة قبل اعتماد المعلم

هذه تجربة غير معتمدة وغير معممة. لا تعديل main أو Production. الفرع: preview/shakabumbo-pilot-20261013، مبني على 47ca4c7079e1631dd2643453af447d890765b03c.

## الفحص وما أعيد استخدامه
- React/Vite للواجهات الجديدة، وأدوات المعلم القديمة في legacy.html.
- studentProfiles للملف والذاكرة؛ pilotAttempts داخل الملف لمنع احتساب الإرسال المكرر بعد خروج الحدث من نافذة الذاكرة.
- curriculumTargets لخريطة المهارات وبنك المحتوى، مع عزل إجابات المعلم من جميع إسقاطات الطالب.
- assessments للتقييم الرسمي؛ لا يكتب محرك التعلم فيه.
- remediationPlans للخطط باعتماد المعلم، homeworkEvidence لتتبع الورق وتصحيحه.
- announcements ومكتبة files الحالية والمرفقات المحمية وaccess.js للصلاحيات.
- لا زيادة في عدد نقاط API (12)، ولا قاعدة بيانات أو مورد سحابي جديد.

## المنفذ
- تجربة اختيارية عبر pilot=1؛ بوابة خادم ترفض Production وفروع Preview الأخرى.
- اسم «شكابمبو»، تعلّم/تدرّب/أتقن، استئناف النشاط، تفسير التوصيات، فصل الإتقان التدريبي عن تقييم المعلم.
- متطلبات المهارات، منع دوراتها، مراجعة متباعدة، تشخيص أولي، تغيير استراتيجية الشرح عند تكرار التعثر إذا توفر بديل معتمد.
- ذاكرة شخصية مستمرة مرتبطة بالمعرف؛ لا خلط أسماء متشابهة، ولا تصنيفات نفسية.
- الإعلانات في تبويب مستقل وشارة غير المقروء لكل طالب، قراءة محفوظة، تثبيت وانتهاء وإلغاء نشر ومعاينة وصورة. الصورة نفسها تخضع لنطاق الفصل والانتهاء.
- بطاقة الحفظ بعد شكابمبو، مع مساحة الشريط السفلي، وبطاقة الطالب في الأعلى وفق إصلاح الفرع السابق.
- مركز المعلم لإضافة المحتوى والإجابات واعتمادها، وتعديل الخطط والمرفقات الموجودة وروابط HTTPS، وتصحيح الورق.
- أوراق A4 بالعربية وRTL وخط نسخ محلي مرخص SIL OFL، نسخة طالب وأخرى للمعلم، تتبع الورقة دون اعتبار الطباعة إنجازًا.
- طالب اصطناعي منفصل لتجربة المتصفح، مع ذاكرة منفصلة لكل جلسة رابط demoSession، دون تعديل بيانات طالب حقيقي للاختبار.

## فجوات تمنع إعلان اكتمال الأمر الشامل
- بنك الأسئلة الكامل للكتاب لم يُستخرج ويُراجع؛ الموجود فهرس موثق وتجربة محددة وإدارة محتوى. لا اختلاق اعتماد الأسئلة.
- لم تُحسم نسخة لغتي الرسمية وشروط إعادة نشرها؛ لم يُنسخ كتاب من موقع غير رسمي.
- التلاوات والنص القرآني المرخص لم يدمجا؛ تظل متابعة الحفظ والتوزيع القائمة دون توليد آيات أو احتساب الاستماع حفظًا.
- لا تسميع آلي أو محادثة أو ميكروفون أو تصحيح صور خط آلي.
- اقتراحات الخطط محدودة ببنك المهارات المتاح؛ لا يوجد ادعاء باستبدال المعلم الخصوصي أو التحقق من فاعلية تعليمية على الطلاب.
- الطباعة تستخدم نافذة الطباعة المحلية وحفظ PDF المدعوم من الجهاز؛ لا خدمة توليد مدفوعة، وليست تحويلًا تلقائيًا من الخادم إلى ملف PDF.
- تغيير نموذج ورقة يحتاج بنك أسئلة كافيًا. لا ادعاء أن تغيير معرف الورقة وحده يصنع تدريبًا جديدًا.
- تصحيح/حذف/احتفاظ بيانات الأطفال وموافقة ولي الأمر وسياسة النقل الدولي تحتاج مراجعة مؤسسية قبل التعميم؛ لا ادعاء امتثال قانوني شامل.
- لا تعدد معلمين/فصول في التجربة: يعاد استخدام نطاق الفصل الحالي، ويلزم تعميم نطاق الصلاحيات قبل التوسع.
- حذف الإعلانات حاليًا إلغاء نشر، ولا حذف مدمر للسجلات القائمة.

## الأمان والمراجعة
أُجريت مراجعة مستقلة واحدة؛ كشفت تسرب إجابات عبر المسار القديم، وأولوية إتقان غير صحيحة بعد تعثر لاحق، ووصول صورة إعلان خارج النطاق. وُثقت باختبارات فاشلة ثم أصلحت. نُقل حارس إعلانات التجربة إلى ما قبل قراءة قاعدة البيانات، وأضيف دفتر محاولات دائم لمنع الإرسال المكرر، ومنع تصحيح ورقة بعد تغيير مصدرها. لم تُكرر المراجعة المستقلة.

## التكلفة
لا مزود ذكاء اصطناعي أو مفتاح أو اشتراك أو مورد سحابي جديد. جميع العمليات داخل المشروع الحالي والطباعة على الجهاز. هناك استهلاك إضافي محدود لقراءات وكتابات Firebase وطلبات Vercel الحالية؛ حُددت المحاولات إلى 3–20 يوميًا وفق المحتوى والورق إلى 10 يوميًا. الذاكرة الساخنة 200 محاولة. لا يمكن إثبات صفر تكلفة إجمالية أو حدود الحساب الفعلية من هذه الأدوات؛ لم تكشف بيانات الفريق خطة الفوترة، ولم تُغيّر إعداداتها. التحقق من حصص Firebase والفوترة شرط قبل التعميم.

## التحقق
تسجل نتائج التشغيل الفعلية والرابط وCommit والمعاينة في ملحق التسليم. لا تُعد اختبارات قاعدة البيانات الاصطناعية إثباتًا لاتصال Firebase على Preview؛ ذلك يتحقق بالمتصفح بعد النشر.

## إصلاح صورة الطالب التجريبي
سبب العطل: student_profile يدخل مسار القائمة الحقيقية، التي لا تحتوي __shakabumbo_demo__، فيرجع STUDENT_NOT_FOUND (404). أضيف توجيه محدد لهذا المعرف مع pilot=true، وحفظ الصورة والهوايات في studentProfiles بمعرف جلسة تجريبية مستقل. قراءة home تسترجع الصورة والهوايات من الجلسة. تحقق الملف والحجم مشترك مع مسار الطلاب الحقيقيين؛ لم تتغير صلاحياتهم. اختبارات API تثبت الاستمرار بعد إعادة القراءة، وعدم خلط الجلسات، ورفض القيم غير الصالحة، ومنع Production. نجح 69 اختبارًا والبناء بإعدادات Preview.
